# protastim
Project, Task and Time management

Because while TODO systems are aplenty, managing multiple projects and planning their separate tasks together with time tracking, isn't quite as simple

A helpful TUI program for personal usage in protastim comes to the rescue

## Usage
```bash
git clone https://github.com/Asfolny/protastim
cd protastim
go run ./...
```
